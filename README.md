# 词阶 · WordTap

Windows 划词英语词典。选中英文，按快捷键查看英英释义、中文翻译或简明英文改写。常见词和习语可以直接离线查。

**[下载 Windows 安装包](https://github.com/Xuziru00/WordTap/releases/latest/download/WordTap-Setup-win-x64.exe)** · [下载免安装 ZIP](https://github.com/Xuziru00/WordTap/releases/latest/download/WordTap-MVP-win-x64.zip) · [反馈问题](https://github.com/Xuziru00/WordTap/issues/new/choose)

支持 Windows 10/11 x64。

## 开始使用

1. 运行安装包，首次使用可以选择便携版，装好即可查词。也可以解压 ZIP，双击 `WordTap.exe`。
2. 在浏览器或文档中选中英文，按 `Ctrl + Alt + E` 看英英结果，或按 `Ctrl + Alt + C` 查看中文结果。快捷键可在设置中更改。
3. 查询整句时，可按提示下载本地模型，也可从「设置 → 本地模型」安装。装好后可离线使用。

## 功能

- **离线词典**包含 50,000 条核心词条和约 1,000 条习语。高频词有「基础词」标记，查变形词时可看到原形释义。
- **一层一层查**，可点击英英释义里的生词继续查询，再返回上一层。浮层可固定、移动和缩放。
- **发音与收藏**，单词可用系统语音朗读。点星标加入本地单词本，支持 Markdown 导入和导出。
- **整句翻译和改写**由本地模型处理。英文改写以 B1 或更简单为目标。

## 常见问题

**为什么某些软件读不到选区？** 词阶先尝试直接读取，再尝试借用剪贴板。遇到不可复制的内容，可以打开托盘里的词阶主页，手动粘贴查询。

**升级要重新下载模型吗？** 用新版安装包沿用原目录。完整版会校验并复用符合要求的已下载模型。只更新软件和词库时，可以选择便携版。

**下载安装后 Windows 出现提示？** 当前安装包未做 Authenticode 签名。请核对下载来源与发行版附件中的 SHA-256 值。
